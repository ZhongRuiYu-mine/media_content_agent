# 新媒体信宣智能体（media_content_agent）

把社团活动的散乱素材，变成**可直接送审的稿件**，而且**每一句话都能点回原素材**。

面向大学社团媒体部：通知、纪要、群公告、采访转写、照片说明丢进去，系统切句、逐句裁决、
建素材图（带来源权威度），检出缺口，按缺口出选题成稿，再把稿件里每个数字/人名/职务/时间/地点
逐项核回素材。核不回来的，列成《待核实清单》——让你带着清单去找主办方确认，而不是带着印象写稿。

> 详细设计与逐文件改造依据见 **[design/11_内容域改造方案.md](design/11_内容域改造方案.md)**。
> 本目录（`deliver/`）就是**交付物**：内容域工作台本体 + 它自己的测试与工具。
> 面试域历史资产（旧引擎、旧设计 01–10、PPT 制作脚本、调研报告等）在上层 `legacy/`，
> 不在交付范围内，也不参与运行。
>
> **当前进度**：阶段 0–4 全部完成（内容域地基 → 采编相 → 发布相 → 智能体相 → 收口）。
> 一个命令就能把演示起点准备好：`tools/prepare_demo.py`。

## 两个边界（先说清楚）

1. **不替用户造事实。** 系统只做"素材里有的"；素材里没有的，进《待核实清单》，不编。
2. **不做"AI 自动审核"。** 系统做的是**核验与留痕**，审由人做。导出的《审核记录》是给审稿人用的
   证据与记录工具，不是审核结论。

## 核心主张：溯源链

| 机制 | 做什么 | 用不用 LLM |
| --- | --- | --- |
| 溯源链 `cites` | 稿件每句话建一条有向边指回素材，前端点击即可跳回原文 | **不用** |
| 事实核验 | 抽断言（数字/人名/职务/时间/地点），在素材库找支撑；找不到就是"无据"，**阻断发布** | **不用** |
| 缺口检测 | 无据 / 矛盾 / 孤证 / 过期 / 涉隐私 五类，全确定性规则 | **不用** |
| 缺口驱动选题 | 素材多但无稿、有稿但素材薄、往届有今年无 | 粗筛精排不用，出选题 1 次 |
| 双轨渲染 | 轨一确定性模板成稿（事实基线）；轨二授权润色（只改表达，不许动事实） | 轨一不用 |
| 时间点回滚 | 素材图按 seq 全量回滚，稿件与多平台版本联动回退 | **不用** |

LLM 只在高价值点使用，且全部经闸门授权与审计（`data/logs/llm_gate.jsonl`，**不含正文**）。
`LLM_GATE_MODE=auto_deny` 可全拒 LLM，用来证明"确定性链路自己就能跑通"。

## 六步两相

```
采编相 editorial                          发布相 publish
① 素材录入 ─ ② 缺口检测 ─ ③ 选题成稿  →  ④ 事实核验 ─ ⑤ 多平台适配 ─ ⑥ 审核留痕
（切句+逐句裁决）  （五类缺口）  （六段结构）  （断言溯源, 阻断无据）
```

③ 与 ④ 之间是**门禁**：带阻断项的稿件不许进入多平台适配。

## 快速开始

1. **依赖只有两个**（核心档）：`python 3.10+` + `starlette` + `uvicorn`。

   ```bash
   python -m pip install -r requirements.txt
   D:\jiuwen\Scripts\python.exe tools\check_env.py     # 自检：这台机器能跑到哪一档
   ```

   `openjiuwen`（jiWen 运行时，**不是 PyPI 包**）只用于大模型/团队路线，**不装也能跑完整演示**
   （核验/缺口/成稿/三渠道预览/六角色确定性辅助/账号）。三档说明见 **[交付说明.md](交付说明.md)**。
   下文 `python` 指你的解释器（本机是 `D:\jiuwen\Scripts\python.exe`）。
   **所有命令都在本目录（`deliver/`）下执行。**

2. **自检**（不需要任何 Key）：

   ```bash
   D:\jiuwen\Scripts\python.exe test\_test_stage1_content.py   # 采编相
   D:\jiuwen\Scripts\python.exe tools\check_acceptance.py       # 四条验收 A1/A2/A3/A5
   ```

3. **配置**：复制 `.env.example` 为 `.env`，填 LLM Key。**不填也能离线跑**
   （规则出稿 + 用户裁决）；要零 LLM 演示就把 `LLM_GATE_MODE=auto_deny`。

4. **向量（可选）**：模型在 14GB 量级，**不必拷进本项目**，指过去即可：

   ```
   EMBEDDING_LOCAL_DIR=<你机器上模型目录的绝对路径>
   ```

   或用 `EMBEDDING_BASE_URL` 指 OpenAI 兼容端点；两者都不可用会自动降级为纯规则
   （事实核验与缺口检测本来就零向量，降级不影响核心能力）。

5. **准备演示数据（推荐第一次就跑）**：

   ```bash
   D:\jiuwen\Scripts\python.exe tools\prepare_demo.py
   ```

   它会清库 → 灌入演示语料（历史层 + 当年层）→ 跑完整链路 → 导出《审核记录》与「宣发包」
   → 打印自检表（五类缺口必须齐全）。最后一行 `自检: 通过` 才算准备好。

6. **启动**：

   ```bash
   D:\jiuwen\Scripts\python.exe server.py
   # 三栏工作台  http://127.0.0.1:8080/workbench   ← 唯一界面
   # 根路径 / 与 /review 都指向同一个工作台（旧面试界面已退休）
   ```

   服务自带进程令牌鉴权（启动注入页面），默认只接受本机 Host、不放开跨域。

   **界面上的常用事**（一屏三列，左=素材池 / 中=组装 / 右=辅助与预览）：

   | 操作 | 怎么用 |
   | --- | --- |
   | **拖素材组稿**（核心动作） | 左栏一条素材（拖标题=整条）或一个分句都能拖到中栏：**先拖的在上**，落点决定插在哪两块之间。拖进中栏的素材/分句**从左栏消失**（它是被用掉了） |
   | 收回 | 中栏那块点 `✕`（或把它拖回左栏），素材就回到池子里，随时能再拖 |
   | 调顺序 | 后续再拖；或用键盘 `Alt+↑/↓` 挪选中块、`Delete` 拿掉 |
   | 溯源点击 | 点块下的来源徽章 → 左栏对应素材高亮并亮出依赖连线 |
   | 粘素材 | 左栏顶部**只有一个**输入框：粘进去停一下自动切句 → 点「存进去」（`Ctrl+Enter` 更快），零 LLM |
   | **六个角色**（中栏下半） | 单选或多选任意组合（事实核查员/合规风险审查/文案编辑/多平台运营/传播效果分析师/采编主持），点「启动智能辅助」→ 右栏上半逐条滚出意见。**配了 API 就走团队路线（多智能体，逐个发言）；没配就落确定性版本，零 Key 也能出意见** |
   | 应用建议 | 意见里带「应用：…」的按钮可以直接改稿（脱敏 / 删无据块 / 拆长句 / 收敛到上限），改完会说明改了几处；**改不改由你点** |
   | **三渠道预览**（右栏下半） | 订阅号 / 短视频 / 海报并排，拖一下就重算；海报按「主体 / 一个数字 / 时间地点」排槽位，抽不到的槽位标空并写明原因 |
   | 核验 / 发布 / 导出 | `⌘K` 命令面板：核验、多平台适配、审核记录、宣发包、回滚、仪表盘、选题…都在里面 |
   | 设置（右上角） | 注册 / 登录 / 退出 + 每人一份 API 配置（Base / 模型 / Key，含「测试连通」）。**不登录、不配 Key 也能用全部核心功能** |
   | 主题切换 | 右上角主题按钮或设置里的「外观」循环 **深色 / 浅色 / 纸质**；默认深色（长时间读稿护眼），选择记在本地 |

   **顶部只有 3 个入口**（命令 / 主题 / 设置），没有第二排按钮。

   **两份稿互不覆盖**：系统自动成稿落轨一 `base`（事实基线，平台渲染与回滚认它）；
   你拖出来的那版落组装轨 `compose`（首屏恢复用，刷新后看到的是自己改的稿）。
   核验对象永远是你提交的那一份组装稿。

   **预览与发布不是一回事**：`/api/content/preview` 只是看样貌（`无门禁`，拖一下就重算）；
   发布走 `/api/content/platforms`，要过核验门禁。

7. **可选 MongoDB**：默认 `mongodb://127.0.0.1:27017/media_content`，启用选题库与文体意图库；
   不可用时自动降级为文件兜底，不阻塞（`design/11` §12 R5）。

## 界面与配色

前端只有一套：`static/workbench.*`（约 1.9k 行，零构建、零 npm 依赖）。

| 文件 | 作用 |
| --- | --- |
| `static/tokens.css` | **颜色令牌**：深色（默认）/ 浅色 / 纸质三主题；改色只改这一层 |
| `static/workbench.css` | 版式与组件；只引用令牌，不写颜色字面量 |
| `static/doc-board.js` | 积木流模型（先到在上、一块=一段、按位置出 segments） |
| `static/links.js` | 溯源连线叠层（默认不常驻，选中时亮一下） |
| `static/workbench.html` / `workbench.js` | 三列结构与交互（拖素材 / 六角色 / 三渠道预览 / 设置 / 命令面板 / 主题） |

配色是**按语义分配**的，不是按好看分配：

| 语义 | 用在哪 |
| --- | --- |
| 青绿（`--acc` / `--c-cite`） | 可点、当前态、溯源链、右栏同步高亮 |
| 红（`--c-block`） | 阻断：无据 / 矛盾 / 涉隐私 |
| 琥珀（`--c-warn`） | 警告：孤证、过期（往届信息） |
| 灰绿（`--c-ok`） | 已核验、导出凭证 |
| 柔紫（`--c-resolve`） | 已裁定：用户裁决 / 按权威度先裁定 |
| 五档权威度（`--auth-*`） | 官方金 / 主办方青灰 / 现场石板蓝 / 口述棕 / 转述灰 |

`tools/check_contrast.py` 把"护眼"变成数字：三主题下正文对比度 ≥7:1、次要文字与徽章 ≥4.5:1、
弱提示 ≥3.5:1，不达标直接报错（这比"看着挺舒服"可靠）。

### 六个角色有两条路线（界面上同一个按钮，引擎不同）

中栏下半那六个角色，点「启动智能辅助」时按**有没有配好 API** 自动选路线，右栏状态会写明是
哪条，不会让人猜：

| 路线 | 走什么 | 什么时候用 | 特点 |
| --- | --- | --- | --- |
| **团队路线**（配好 Key） | `/api/content/review` → SwarmFlow 多智能体，按勾选的角色**逐个点名发言**，SSE 流式滚进右栏，最后由主持汇总 | 有 Key 且闸门放行 | 这是 `design/11` §9 的「智能体相」；角色真的在读素材库、待核实清单与渲染稿 |
| **确定性路线**（没 Key / 团队起不来） | `/api/content/assist` → `content/assist.py` | 零配置、断网、演示兜底 | 零 LLM、结论可复现，且每条意见带**可一键应用**的改稿 action |

团队路线**失败会明说再降级**（"团队起不来：…→ 改走确定性版本"），不让人卡在一个转圈的按钮上；
25 秒一个专家都没开口也会自动降级。命令面板里还能手动指定走哪条：
「确定性复核这一稿（不调 API）」/「采编复盘（六角色团队 · 走 API）」。

两条路线里各角色管什么（团队路线的提示词见 `components/review_runtime.py`
的 `_CONTENT_EXPERT_SEQUENCE`，确定性路线见 `content/assist.py`）：

| 角色 | 管什么 | 确定性路线能一键做的改动 |
| --- | --- | --- |
| 事实核查员 | 逐块跑断言级核验，报块级缺口（素材级孤证单独说，不混算） | 删掉整块无据的块 |
| 合规风险审查 | 隐私模式 + 绝对化/效果承诺用词 | 命中串脱敏成 `***` |
| 文案编辑 | 超长块、超长字幕（移动端读不完） | 按句拆开 |
| 多平台运营 | 三渠道字数/空分镜/缺槽位 | 收敛到平台上限内（试算前 N 块） |
| 传播效果分析师 | 来源结构与现场感，只给可核对的观察点 | —（不编数字） |
| 采编主持 | 汇总成"这一稿最该先解决的一件事" | — |

大模型只在**不改事实的表达层**加分（润色/合规复核/多平台改写那几个授权点），
且要过断言级 diff。预览也不一样：`/api/content/preview` 无门禁（还没定稿就该能看样貌），
发布才过门禁。

**界面不显示权威度分数**：素材来源只写「官方文件 / 主办方 / 现场 / 口述 / 转述」，
分数留在导出件（《审核记录》）里给审稿人核对——界面上把判断变成算术题没有意义。

### 一处历史命名保留

数据模型与若干配置键里仍能看到 `student_id` / `RESUME_DIR` / `OJ_MEMORY_DIR` 这类**旧键名**
（见 `design/11` §13 C9）：它们是数据文件里的中性白名单键，改名会让已有素材图读不出来，
收益为零、回归风险实打实。**对外文案与新增模块一律用内容域的说法**，界面与提示词里没有
「面试 / 简历 / 事件库」这类字眼。
