## 重拍

```bash
cd deliver
D:\jiuwen\Scripts\python.exe tools\capture_shots.py
# 只拍其中几张
D:\jiuwen\Scripts\python.exe tools\capture_shots.py --only 05,09
# 两倍高清
D:\jiuwen\Scripts\python.exe tools\capture_shots.py --scale 2
```

脚本做的事：用**临时数据目录**起服务（不动 `data/` 里的演示数据）→ 给两个独立工作区
`shot_a` / `shot_b` 各灌一份演示语料并出一版稿 → 逐场景截图 → 关服务、删临时目录。

## 两点须知

1. **场景靠页面自带的 `?scene=` 参数**（`stack` / `palette` / `checklist` / `assist` /
   `dashboard` / `record` / `settings` / `topics`，另有 `&theme=light|paper`、`&club=`）。
   它只调用界面上本来就有的动作，不注入假数据。
2. **Edge 无头模式在受限沙箱里会失败**（`mojo platform_channel ... 拒绝访问`）。
   遇到就换一台能正常起浏览器的机器跑，或者在允许的权限下跑；
   脚本会把这条原因打出来，而不是给你一张半截图。

## 为什么不画示意图

配图要能扛住"这真是你们做的东西吗"这一问。截图上的每个数字（11 条素材、8 条缺口、
23/60 海报字数、LLM 调用 0 次）都是当场算出来的，改了界面重跑一次就对得上。
